# Episodic Memory

Episodic memory stores **specific historical experiences** — the concrete record of what happened.

## Stores

- Previous trades
- Planner decisions
- Evidence gathered
- Outcomes

## What it is good for

> Useful for finding similar past situations.

When the planner faces a new goal, episodic memory answers *"have I been here before, and how did it turn out?"* Retrieved episodes give the planner precedent it can reason from (see [retrieval.md](retrieval.md)).

## Relationship to other memory types

- **Episodic** = the raw experience ("on this date, given this evidence, this decision led to this outcome").
- **Reflection** = the lesson drawn from experiences (see [reflection-memory.md](reflection-memory.md)).
- **Semantic** = generalized knowledge distilled over many episodes (see [semantic-memory.md](semantic-memory.md)).

Episodes are the ground truth from which reflection and semantic memory are derived.
