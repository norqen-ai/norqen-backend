# Semantic Memory

Semantic memory stores **generalized knowledge** — facts and abstractions that hold across many specific episodes.

## Stores

- Company descriptions
- Market concepts
- Trading terminology
- Learned abstractions

## Key property

> Semantic memories evolve independently of specific episodes.

A fact like "this company operates in a cyclical sector" is not tied to any single trade; it is durable knowledge refined over time. This is why semantic memory has its own lifecycle and ranking, separate from episodic memory (see [memory-types.md](memory-types.md)).

## Relationship to other memory types

- **Episodic** captures individual experiences (see [episodic-memory.md](episodic-memory.md)).
- **Semantic** distills recurring truths from many experiences.
- **Reflection** captures corrective lessons (see [reflection-memory.md](reflection-memory.md)).

Semantic memory gives the planner background understanding, so it does not re-derive well-established facts on every run.
